🔥 About Naam Ka Kamaal

Naam Ka Kamaal is an interactive web entertainment application built by Aayush Gund. Designed for viral friend roasts, users can enter any name to receive custom personality meters (Chaos Energy, Bahana Generator, Neend Power) along with humorous title badges like "Last-Minute Legend".

⚡ Product Highlights

🌐 Multi-Language

Available in English, Hinglish (Recommended), and Hindi.

📊 Dynamic Stats

Live percentage meters analyzing fun traits and habits.

🎯 Custom Titles

Unique roasts and badges tailored per name input.

📲 Social Ready

Aesthetic dark mode UI built specially for WhatsApp & Instagram sharing.
